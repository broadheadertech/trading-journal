Inner Circle Concepts

ICT methodology — order blocks, fair value gaps, and liquidity engineering used by institutional traders.

Key concepts

Order Blocks (OB) — last bullish/bearish candle before a strong directional move
Fair Value Gaps (FVG) — three-candle imbalances that often get filled
Breaker Blocks — failed order blocks that flip role
Liquidity Pools — equal highs/lows where stops cluster
Premium vs. Discount zones via dealing range

Trading rules

1Identify the daily/4H bias using market structure first
2Mark order blocks and FVGs on your trading timeframe
3Wait for liquidity sweep before entering
4Stop loss above/below the order block, not at the wick
5Target the next opposing liquidity pool

Install instructions (MetaTrader 5)

One-time setup. Takes about 5 minutes. The EA only reads your trade data — it cannot place trades.

1
Download the EA
Download atlas-sync.mq5 atlas-sync.ex5 (if compiled)

Most users want the .mq5 source. Drop it in MT5’s MQL5/Experts folder, then in MT5 right-click atlas-sync in Navigator → Modify → Compile (F7). MT5 will produce the .ex5 automatically. The .ex5 button above is for cases where the developer pre-compiled and uploaded it.

2
Open MT5’s data folder

In MT5: File → Open Data Folder, then go into MQL5 → Experts. Drop atlas-sync.ex5 in this folder.

3
Allow the webhook URL

In MT5: Tools → Options → Expert Advisors. Tick “Allow WebRequest for listed URL” and add this URL:

https://keen-seal-901.convex.site/api/mt5-sync
4
Restart MT5

Close MT5 fully and reopen it. You should see atlas-sync in the Navigator panel under Expert Advisors.

5
Attach to a chart + paste token

Open any chart (any symbol). Drag atlas-sync from Navigator onto it. In the EA’s “Inputs” tab, paste your token:

Click OK. A smiley face in the top-right of the chart means it’s running. The EA will backfill your last 90 days on startup, then sync new trades as they close.

MT5 must be running for trades to sync in real time. If MT5 is offline, the EA backfills any deals that closed while it was off the next time you open it. For 24/7 sync, run MT5 on a VPS — VT Markets offers a free VPS.
